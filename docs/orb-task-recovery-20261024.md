# 任务状态恢复修复（2026-10-24 本地预览）

## 问题与处理

只读独立探测能读到正在进行的本地任务；模拟账号重置后，同一来源返回 `no-verifiable-lifecycle`。这证明重置路径会丢失开始记录，但不等同于直接读取了旧常驻进程的内部错误。

修复将“暂时无法确认账号”和“确认换了账号”分开：

- 首次账号确认不丢弃已存在的任务开始记录。
- 收到账号通知时立即隐藏旧显示、提升异步世代，等待有效账号响应；同账号确认不重复截断生命周期。
- 保留上一次已确认账号的内存指纹，真正换号或退出登录仍清理任务历史。旧账号持续活动不能让旧任务重新出现在新账号下。
- 账号待确认、认证错误及认证恢复未完成时，真实任务回调不得更新界面；过期世代的回调同样丢弃。
- 启动时先显示读取状态；“未观测到有效任务记录”与“来源读取失败”采用不同说明，不把未知数量伪装为零。

皮肤、七档尺寸、沿弧渐变和纯白任务栏均保留。任务仍是有限的本地观测，不证明全账号数量，也不补造计划步骤。
