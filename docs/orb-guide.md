# 玻璃悬浮球使用说明（0.4.0 预览）

## 打开与切换

右键应用托盘图标，选择“玻璃悬浮球”；也可在“外观设置”的显示模式中选择。原来的桌面悬浮条和窗口吸附模式继续保留。

首次启用为“紧凑”尺寸，位于主屏右下工作区。七档为极小（50%）、小（75%）、迷你（85%）、紧凑、标准、大、大号。悬浮球尺寸不叠加原悬浮条的整体缩放。

展开顶部任务状态栏采用不透明纯白色。极小和小对折叠及展开两种形态同时缩放；可在托盘“窗口尺寸”或外观设置中选择。

## 皮肤配色

在托盘“悬浮球皮肤”或外观设置的悬浮球区域选择奶油白、冰川蓝、薰衣草紫。配色同时作用于折叠/展开背景、额度环和周额度条；顶部任务栏始终纯白，在线、错误和到期预警颜色不变。设置支持实时预览，取消不保存，重启保留已保存皮肤；旧配置或无效配色默认使用奶油白。原悬浮条配色及设置窗口/托盘菜单自身的奶油风格不受影响。

额度环与任务进度环从顶部顺时针沿弧长渐变，不按屏幕上下方向渐变；彩色弧线长度仍对应显示的百分比，未填充部分保留中性底色。

## 鼠标操作

- 移入约120毫秒展开，移出约260毫秒收起，可在设置调整。
- 左键拖动保存位置；一次开合在同一屏幕保持展开方向，避免跨过屏幕中线时跳边。
- 双击打开设置；右键打开应用菜单。
- 关闭“鼠标移入时展开”后，用单击切换展开与折叠。
- 设置中可以关闭动画或顶部任务区域，调整透明度、柔光、圆角系数。
- 同屏全屏时隐藏，退出后以折叠状态恢复；普通最大化不按全屏处理。

## 数据含义

折叠时显示5小时额度环与7天额度条，数字服从“剩余/已用”设置。绿色状态点代表额度连接最近有效，不代表任务一定正在运行。未知额度使用“—”，不会补成0或100%。

展开后显示额度、重置券数量和最早到期日。重置券只读，程序没有核销操作。零券与读取失败分别展示；短暂失败保留缓存并标记。

当前任务来源为Codex Desktop本地结构化生命周期记录，界面标“已观测”，覆盖范围有限，不能作为全账号或整台电脑的完整任务统计。已验证可关联本机真实会话的开始与持续活动；本轮结束和中断按结构化记录处理。没有事件不意味着全局空闲，长时间不能确认会标记过期。

重启后的首次账号确认、同账号重复通知和认证恢复不会再次丢弃任务开始记录；账号尚未确认时隐藏数量并显示读取状态。确认切换账号或退出登录后清理旧任务，必须观测到新的有效任务生命周期才恢复统计，不能把旧账号活动接到新账号下。未找到有效记录与读取来源失败分别提示，不会将未知数量显示为零。

当前样本没有计划步骤和审批等待的可靠字段。因此没有真实计划时显示“未提供步骤”，不会把工具次数、token或耗时变成进度；仅生命周期结束不显示成“成功完成”。源不可用时明确提示错误，不造“2/5”。详细范围见[能力报告](capability-report.md)。

## 设置保存

修改可实时预览，保存后落盘；取消/关闭恢复进入前的外观与位置。预览中标“示例数据”，其中的2/5、100%、84%与3张券不是账号实测值。

配置采用同目录原子替换，前一份保留为settings.json.bak；损坏的原配置另行保留。写入失败会提示并保留编辑窗口。旧版本用户的模式、位置、配色和缩放不强制改变。

## 本地开发与预览

日常运行保持单实例。需要与旧版本对照时，从独立目录运行：

```powershell
.\CodexRateMonitor.exe --development-instance --settings
```

已经运行时再次带--settings会请求打开该实例的设置。开发实例可正常关闭为：

```powershell
.\CodexRateMonitor.exe --development-instance --shutdown-development
```

关闭命令仅针对同目录的开发实例，不会结束日常实例或用户的Codex任务。正式切换日常版本时，先从旧应用菜单退出，再使用新目录运行；不要覆盖正在使用的EXE。升级前备份旧配置，需要回滚时恢复旧目录和对应配置。
